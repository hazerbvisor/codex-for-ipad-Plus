# macOS Codex appearance

Native SwiftUI uses a neutral project sidebar, a centered workspace welcome screen,
flat assistant replies, user message bubbles, and one rounded composer with model
and reasoning controls. The inspector opens on demand. Compact windows retain the
thread browser and touch controls; keyboard shortcuts, Dynamic Type, VoiceOver,
and reduced-motion support remain available.
